# 识间 · 中文反诈骗网站 MVP

帮助用户描述可疑经历、识别危险信号，并先找到可执行的下一步。当前是纯前端测试版，无账号、后端或 AI 服务。

## 本地运行

要求 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。其他命令：`npm test` 检查风险规则，`npm run build` 检查 TypeScript 并生成 `dist/`，`npm run preview` 预览构建版。

## 当前功能

- 首页描述输入、三个快捷入口、首次访问提示。
- 独立的 `src/riskAnalyzer.ts`：关键词与组合规则，四个风险等级，先展示行动建议。单个词不作为诈骗定性。
- Scam Graph：10 个核心机制，点击展开具体套路，支持拖动和缩放；同一案例可关联多个节点。
- 紧急模式：六种场景及短清单。
- 12 个静态案例，含路径、危险信号和付款前后建议。
- 案例投稿：使用 `localStorage` 保存在本设备，可在本设备查看和删除。

## 项目结构

```text
src/
  App.tsx                 页面、路由和表单
  GraphPage.tsx           交互图谱
  riskAnalyzer.ts         可独立替换的判断规则
  riskAnalyzer.test.ts    规则自检
  data/cases.ts           案例数据
  data/graph.ts           图谱节点和关系
  styles.css             视觉与响应式样式
```

技术栈：React、TypeScript、Vite、Tailwind CSS、React Router、`@xyflow/react`。首版使用 Vite 默认单页部署模式，部署到静态托管时需把未知路径回退到 `index.html`。

## 隐私与边界

首页描述只在当前页面内用于规则判断，不发送给服务器。投稿及首次访问提示状态写入浏览器 `localStorage`；清理浏览器数据可能删除投稿。请勿填写身份证号、银行卡号、验证码、家庭地址等敏感内容。案例与规则仅提示行为风险，不对具体商家或个人作诈骗认定，也不替代官方核实或专业意见。

未来若接入 AI/API，应先明确告知数据会发送到哪里、取得用户同意，再在 `riskAnalyzer.ts` 的调用边界接入服务；不要直接把原始描述或投稿静默上传。

## Roadmap

- **下一阶段**：完善可解释的规则、图谱内容与可访问性；加入用户可选择的数据导出。
- **以后按需求评估**：真正的 AI 判断、后端数据库、账号系统、Scam Radar、B站/小红书自动采集、社媒与投稿 AI 聚类、案件中心、证据管理、报案材料、公安/12315 接口、自动打码。
- 图片上传暂未实现。若将来加入，必须先提醒用户自行遮挡身份证号、银行卡号、家庭地址、验证码及他人隐私，并保留未经修改的原始证据。
